## Обозначения и общий контракт

EXISTS — существовало на исходном SHA. NEEDS_EXTENSION — необходимое расширение. MISSING — серверного сценария нет. BLOCKED_BY_PO — нужно конкретное продуктовое решение. IMPLEMENTED — код и проверки нового блока завершены локально. INTEGRATED — только после фактической проверки Integration; **ни одной строке этот статус сейчас не присвоен**. Для каждого нового маршрута Integration-статус — **не проверено, не подключалось этой задачей**.

В таблицах пути API без префикса означают `/api/v1/`; `v2/...` означает `/api/v2/...`. S — настоящая session-cookie; W — S и свежий CSRF; P — customer; E — performer; O — владелец/участник; M — staff и указанное отдельное permission. Demo activeRole не является полномочием. POST/PATCH/PUT/DELETE с чужим Origin/без CSRF запрещены. Чужой приватный объект — 404, отсутствие роли/права — 403, ошибки полей — 400, конфликт редакции/намерения — 409, недоступный тариф — 503. Приватные ответы no-store. Точные DTO и примеры централизованы в [API_CONTRACT.md](API_CONTRACT.md) и [REGISTRATION_API.md](REGISTRATION_API.md), а не копируются в конкурирующую спецификацию.

DTO: **Reg** — существующий registration; **Account** — id/Reg/capabilities; **Cabinet** — проекция профиля, статусов, модерации и доступных источников; **Version** — `{revision,request_key}`; **Decision** — Version + `{decision,reason?}`; **Example** — метаданные ссылки/закрытого файла; **Draft** — Version + разрешённые поля услуги; **Service2** — публичная услуга с revision/category/extras; **Quote2** — сохранённый quote_id и полный снимок условий/5%; **Order2** — снимок заказа, revision, available_actions, unpaid; **Conversation** — id/order_id/participant_ids; **Message** — server id/sequence/sender/time/text/status/rules; **Case** — конкретное удержанное сообщение и обжалование; **Page<T>** — count/next/previous/results, кроме cursor messages без count.

## Информационные страницы и незакрытые соответствия

`/about`, `/rules`, `/safety`, `/support` показывают редакционный контент Frontend; серверный endpoint не нужен для статического текста. Если `/support` станет формой обращения, создание/чтение support case — MISSING, нужны поля/адресат/сроки/доступ. `/notifications` — MISSING: модель событий/доставки/прочтения ещё не согласована. Категорийный и университетский справочники — MISSING; новые фильтры category/min_price/max_price/min_duration/max_duration/ordering — IMPLEMENTED; рейтинговый фильтр недоступен; название университета сейчас свободный приватный текст, а не выдуманный ID справочника. Публичное портфолио и публичный аватар не разрешены новым приватным файловым контрактом.
