## Основания для обращения

Статус Active и результат VNC сообщены владельцем. Результаты SSH/TCP получены проверками с Mac; они не доказывают конкретную причину отказа. Возможная блокировка IP, ошибка сети и проблема сервиса VNC остаются версиями для проверки.

VNC в VMmanager работает через noVNC/WebSocket и инфраструктуру платформы. Параметры узла проверяет провайдер; публикация Django не требуется для появления консоли ОС.
