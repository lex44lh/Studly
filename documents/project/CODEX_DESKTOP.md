# Codex Desktop: завершение настройки трёх пространств

## Подтверждённое ограничение, 18.10.2026
Через список проектов/чатов проверено: «Основная Разработка Frontend», «Frontend Redesign 2.0» и «Интеграция Frontend с Backend» используют `/Users/alekspih/Documents/ChatGPT/Studly`. Зарегистрированный проект Studly также указывает туда. Это не актуальный каталог разработки.

Доступные инструменты Desktop не предоставляют смену cwd существующего чата на произвольный путь. Handoff переключает другой чат между его checkout и managed worktree, а не назначает нужный ручной worktree; текущий чат не может перенести себя. Добавление в проект не заменяет предоставление доступа к исходной папке. Попытка осмотреть интерфейс через Computer Use отклонена: управление самим приложением Codex этим инструментом запрещено. Это ограничение автоматизации; нельзя утверждать, что в установленном интерфейсе вообще отсутствуют другие ручные варианты. Старые чаты и проекты сохранены.

## Что владельцу сделать вручную
1. В боковой панели Codex откройте действие добавления проекта/папки (обычно «+» у Projects или «Add project / Open folder»; точное название в этой версии через инструмент не проверено). Выберите существующую папку `/Users/alekspih/Projects/studly`. Не выбирайте старую Documents/ChatGPT/Studly.
2. Создайте **новую локальную сессию** внутри добавленного проекта. Выберите Local, а не создание нового Worktree: нужное дерево уже подготовлено. Не создавайте новые ветки поверх существующих.
3. Передайте текст из `/Users/alekspih/Projects/studly/documents/project/handoffs/FRONTEND_CORE.md`. Попросите только подтвердить cwd/ветку/HEAD и готовность.
4. Аналогично добавьте `/Users/alekspih/Projects/studly-redesign`, создайте новую Local-сессию, передайте её `documents/project/handoffs/FRONTEND_REDESIGN.md`.
5. Аналогично добавьте `/Users/alekspih/Projects/studly-integration`, создайте новую Local-сессию, передайте её `documents/project/handoffs/FRONTEND_INTEGRATION.md`.
6. Сверьте результаты трёх проверок с таблицей ниже. Если папку нельзя выбрать или названия действий отличаются, пришлите снимок доступного меню; не обходите ограничения редактированием внутренних файлов Codex.
7. Сохраните старые чаты как историю. До проверки новых cwd не давайте старым чатам параллельные задачи на запись кода. Переименование чата, `cd` в одном терминале или смена Git-ветки не доказывают смену cwd чата.

## Приёмка
Для каждой сессии должны совпасть фактическое окружение чата и результаты `pwd`, `git rev-parse --show-toplevel`, `git branch --show-current`, `git status`, `git worktree list`. Все три ветки содержат общий организационный SHA из отчёта. Если фактический cwd остался старым, проверка не пройдена даже при командах с явным workdir.

Сейчас требуется участие владельца: Git-worktree и инструкции можно подготовить автоматически, но эти три привязки не подтверждены. Этап не считать полностью завершённым. [Официальное описание worktrees](https://learn.chatgpt.com/docs/environments/git-worktrees).
