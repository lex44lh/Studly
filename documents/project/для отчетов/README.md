# STUDLY — отчёты Frontend

Актуальный основной каталог по указанию пользователя: `/Users/alekspih/Documents/Projects/для отчетов` (Документы/Projects/для отчетов). Новые отчёты и индекс ведутся там. Эта папка сохранена как историческая копия.

Отчёты фиксируют действия, фактические результаты проверок и ограничения. Исторические копии сохранены в репозитории без секретов и персональных данных. Commit и push требуют отдельного разрешения.

## Структура
- `frontend/registration/` — регистрация.
- `git/` — работа с ветками и публикацией.
- Другие тематические папки создаются при необходимости.

## Правила
Отдельный файл для каждого сеанса и темы: `YYYY-MM-DD_HH-mm_<topic>.md`. В названии — фактическое начало сеанса в Europe/Moscow. Каждая завершённая стадия записывается сразу: начало/окончание, действие, файлы, результат, ошибки. В отчёте обязательны цель, созданные/изменённые/удалённые файлы, проверки, проблемы, ограничения, следующие действия и Git. Не запущенные проверки отмечаются «Не запускалась». Время получают из системных часов с переводом в Europe/Moscow, значения секретов и Telegram initData не записывают.
