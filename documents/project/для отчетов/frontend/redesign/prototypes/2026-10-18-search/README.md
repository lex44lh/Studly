Для повторного локального HTTP-просмотра из корня репозитория:

```sh

```

Открыть адрес, напечатанный сервером, и выбрать `studly-concepts.html` либо обычную галерею. Сервер слушает только127.0.0.1:3118 и отдаёт только `dist`, без API. Остановка — Ctrl+C.

Пересборка единого файла после изменения CSS/JS:

```sh
node 'documents/project/для отчетов/frontend/redesign/prototypes/2026-10-18-search/package-preview.mjs'
```

Это упаковка текста, установка зависимостей и сборка приложения не требуются.

## Равная функциональность

Во всех трёх вариантах: шесть вымышленных услуг/исполнителей с одинаковыми ценами, поиск, категории, фильтры бюджета/срока/избранного, сортировка, добавление в избранное в памяти, окно услуги, пустая выдача. Навигация показана как пример; соседние разделы не реализованы. Заказы, публикация и оплата недоступны. Состояния не сохраняются между перезагрузками, запросов к Django нет.

CSS-only геометрия и типографические обложки — демонстрационные иллюстрации. Рейтинги, отзывы и верификации не выдуманы. Изображения и портфолио будущего Live API не предполагаются.

## Состав

- `dist/app.js`, `base.css`, `platform.css` — общая разметка, сценарии и доступность.
- `dist/themes/*.css` — три визуальных языка; logo path и основной синий сохранены.
- `dist/studio.*`, `index.html` — сравнение размеров/тем/компонентов.
- `dist/device-frame.*` — точный iframe viewport для QA и снимков.
- `screenshots/*` — настоящие браузерные JPEG; `qa-results.json` — проверенные DOM-размеры, контраст выбранных пар и сценарии.
- `brief-*.md`, `DESIGN-CONTRACT.md` — концептуальные решения и границы работы.

Проверки на физических iPhone/Android/Telegram, настоящая клавиатура, GPU/батарея, полевой LCP/INP/CLS и опрос студентов не запускались. Визуальное утверждение концепции ещё ожидается.
