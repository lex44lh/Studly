- Readiness на VPS — 200 на обоих доменах. С Mac HTTP возвращает редирект на HTTPS; прямые HTTPS-запросы зависают после TCP-соединения до завершения TLS. Привязка одного HTTPS-запроса к физическому интерфейсу не изменила результат. HTTPS через диагностический SSH-туннель проходит с доверенным сертификатом. В журналах рабочего домена были ответы 2xx во всех проверенных часовых интервалах. Участок сети и причина таймаутов не подтверждены.
- Обычный аккаунт стенда вошёл по email. `/api/v1/auth/me/` — 200, `/api/v1/staff/me/` — 403, `/admin/` — 404 от Nginx. `/staff` — 200 для оболочки, экран сообщил, что права доступа не подтверждены.
- У активной ограниченной staff-учётки стенда три права: модерация исполнителей, модерация услуг и разбор случаев безопасности. Реальный вход этой учёткой — **Не запускалась** проверка, доступ к ней не был предоставлен. 22 теста Backend на временной PostgreSQL прошли, включая разделение служебных разрешений, работу с портфолио и каталогом.
- Лимит тела запроса на обоих доменах — 12 МиБ в Nginx; максимальный файл портфолио в Django — 10 МиБ. Остаётся место для заголовков формы и остальных небольших полей multipart. HTTP-загрузка и скачивание через новый интерфейс, переключение «Ссылка → Файл → Ссылка» и создание услуги после модерации — **Не запускались**. Клиентский патч требуется получить для совместной приёмки.
