## Подключённые контракты
GET /api/v1/auth/me/ — проверка сессии и повтор после login.
GET /api/v1/auth/options/ — готовность Mini App.
GET /api/v1/auth/csrf/ — перед каждым login/logout, токен только в памяти запроса.
POST /api/v1/auth/telegram/mini-app/ — исходный initData, без initDataUnsafe.
POST /api/v1/auth/logout/ — клиент и операция контекста готовы; кнопки выхода в существующем UI нет, новую не добавляли.
Сессия в AuthContext, формы в существующем RegistrationContext. Не создавались аккаунты, фиктивные success, Next API или серверная бизнес-логика. SDK загружается общим провайдером, повторная отправка блокируется на время активной операции. Abort не равнозначен отмене серверного login: при повторе сначала проверяется /me/.
