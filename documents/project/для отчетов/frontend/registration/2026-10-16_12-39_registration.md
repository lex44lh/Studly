## Ограничения
- Учётная запись не создаётся. Никакой авторизации и серверных запросов регистрации нет.
- Context живёт только внутри register layout; reload или выход из регистрации сбрасывает черновик. localStorage/sessionStorage для регистрации не используются.
- API-интерфейс задаёт только внутренние view models; названия полей/ролей не утверждают JSON-контракт Django. Методы возвращают явное unavailable, не фиктивные серверные данные.
- Действие restore предусмотрено для будущего явного восстановления до редактирования; автоматическая загрузка черновика сейчас не выполняется.
- Telegram SDK используется только для имени/аватара; initDataUnsafe не является подтверждением личности. InitData, токены и user ID не сохраняются и не логируются.
- Портфолио — временное текстовое поле; загрузка файлов и окончательная структура ожидают согласования.
- PNG/JPEG/WebP до 5 МБ — локальное ограничение предпросмотра аватара, не серверный контракт. Потребуется согласовать с Django.
- Ограничение публикации услуги по полноте профиля ещё не подключено; create-service и бизнес-логика не менялись.
- Зависимости, lock-файл, корневой layout, globals.css, BrandMark, каталог, чаты, заказы и избранное не менялись.
